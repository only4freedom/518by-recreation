## 静态观察

REA 对 PE 导入表、定义字符串和 Ghidra 函数目录做了只读检查：

- 使用 Win32 窗口、图形、注册表、文件和网络 API。
- 导入 `bass.dll`、`bassmix.dll`、`bass_fx.dll`，可确认音频播放/混音相关能力。
- 导入 WinINet HTTP API，并包含 `www.518boyin.com/tts.php`、`saveMP3Log2.php` 等字符串，说明程序含网络请求路径；仅凭字符串不能断定请求的完整用途或服务端行为。
- 包含 `python-3.7.9-embed-win32`、`edge-tts.exe` 与 `edge_tts` 模块路径，以及 `--voice=%s` 参数；可确认带有嵌入式 Python/Edge TTS 相关资源。
- 包含 Windows Speech Platform / SAPI 注册表路径和 `Microsoft Server Speech Text to Speech Voice (zh-CN, HuiHui)` 字符串，可确认本机语音路径。
- PE 的定义字符串中提示某些联网播音员受微软服务变更影响。该文案只说明目标版本自己的提示，不能据此保证当前网络语音服务仍可工作。
- Ghidra 报告程序带有 PDB 标识 `518by.pdb`，但分析中没有确认 PDB 可用，因此符号名完整性未知。

## 当前原型

本仓库从零实现，不复用原程序的二进制、资源或反编译代码。当前代码包含：

- WinForms 主窗口与播音内容队列
- Windows SAPI 语音枚举、单条播报、队列播报、重复次数、语速和音量
- 选择 MP3/WAV/WMA 背景音乐目录并循环播放
- 用户设置写入 `%APPDATA%\518byReplica\settings.xml`
- GitHub Actions 的 x86/x64 构建
